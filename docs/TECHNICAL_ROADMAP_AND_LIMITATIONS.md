# HELI-OS Technical Roadmap and Limitations

## Present

- Structured operating folders and instructions
- Portable initialization and self-check scripts
- AI-tool routing and governance guidance
- Improvement-loop records
- Clean-copy portability test

## Next

- Personal briefing system
- Calendar and email intelligence
- Daily self-assessment
- Weekly CEO review workflow
- Open-loop tracker
- Business command brief

## Later

- Approval-based automation
- Connector layer
- Context and memory services
- Drift detection
- Executive dashboards
- Voice interaction

## Limitations

HELI-OS is local and framework-led. The repository does not currently provide a unified application UI, live calendar or email integrations, production deployment, autonomous agents, or measurable business outcomes. These limits are part of the current maturity description, not defects to hide.
